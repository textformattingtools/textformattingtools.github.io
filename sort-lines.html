Sorting Methods & List Formatting Guide

Whether managing a spreadsheet export, cleaning a mailing list, or sorting code imports, choosing the proper sorting algorithm ensures your items appear in the correct sequence.

Operation How It Works Best For
Sort A → Z Standard case-insensitive alphabetical collation based on language locale. Names, glossary terms, book titles, and dictionary indexes.
Natural Sort Intelligently parses embedded numbers so that Item 2 is ordered before Item 10 (unlike standard ASCII sort which places 10 before 2). File names, chapter headings, version tags (v1.2, v1.10), and numbered inventory.
Reverse Lines Flips the vertical order of lines upside down (the last entry becomes the first). Inverting chronologically sorted logs or audit entries.
Remove Duplicate Lines Scans each line sequentially and discards repeated occurrences while preserving the original relative order. Cleaning subscriber lists, deduplicating search terms, and removing duplicate CSV entries.
Shuffle Lines Applies the unbiased Fisher-Yates shuffle algorithm to generate a fair random distribution. Raffles, random team assignments, flashcard practice, and randomized quizzes.
Number Lines Prefixes each non-empty line with an incremental number (e.g. 1. , 2. ). Step-by-step instructions, ranked lists, and recipes.
