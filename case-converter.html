Guide to Letter Case Formats

Letter casing rules differ significantly between formal journalism, academic publishing, social media, and software engineering. Here is a breakdown of how each casing format functions and when to use it:

Case Style Sample Output Common Usage
Sentence case This is an example sentence. Standard prose, emails, articles, and documentation paragraphs. Capitalizes the first letter of each sentence and preserves proper nouns like "I".
lower case this is an example sentence. Removes all capital letters. Used in data cleaning, email normalization, and search indexing.
UPPER CASE THIS IS AN EXAMPLE SENTENCE. Used for high-priority headings, acronyms, warnings, and emphasis.
Capitalized Case This Is An Example Sentence. Capitalizes the first letter of every single word indiscriminately. Useful for names, book chapters, and tabular headers.
Title Case This Is an Example Sentence Standard AP/Chicago title casing. Capitalizes the first and last word, plus all nouns, verbs, and adjectives, while keeping minor articles and conjunctions (a, an, the, and, but, in, on, of) lowercase.
aLtErNaTiNg cAsE tHiS Is aN ExAmPlE SeNtEnCe. Popularized in internet memes, playful text, and sarcastic commentary. Alternates uppercase and lowercase across letters.
InVeRsE CaSe Flips uppercase to lowercase and vice versa Helpful if you accidentally typed text with Caps Lock turned on.
camelCase thisIsAnExampleSentence Standard programming naming convention in JavaScript, TypeScript, Java, and C# for variable and function names.
PascalCase ThisIsAnExampleSentence Used for class names, React components, and types in TypeScript and C#.
snake_case this_is_an_example_sentence Used for Python variable names, database column names in PostgreSQL/MySQL, and file names.
kebab-case this-is-an-example-sentence Standard for web URLs, CSS class names, and Git branch identifiers.

How Title Case Rules Work

Unlike naive converters that capitalize every single word, our Title Case algorithm adheres to published editorial standards (AP Stylebook & Chicago Manual of Style). The first and final word of each line is always capitalized. Minor conjunctions, prepositions, and articles with fewer than four letters (such as a, an, and, as, at, but, by, for, in, nor, of, on, or, per, the, to, vs, via) remain in lowercase unless they begin or end the title.
